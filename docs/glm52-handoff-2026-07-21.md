## 5 个常见坑(已踩过,别再踩)

1. **husky pre-commit ESLint 找不到配置** - `.eslintrc.cjs` root barrier + `ignorePatterns: ['apps/docs-site/', 'apps/admin/', 'apps/user-spa/', 'packages/']`
2. **lint-staged 路径含空格**("Claude Code Haha") - `.lintstagedrc.cjs` 用函数形式 + `quote()` 包引号 + 排除 apps/admin / apps/docs-site / apps/user-spa / packages
3. **commitlint subject 大写报错** - subject 必须**小写**,footer 行宽 ≤100
4. **Prisma JsonFilter 不支持 `path+equals`** - 改为 `findMany` 后端 `.filter()` 处理
5. **LXD 嵌套容器 `docker exec CMD` 报 breakout** - healthcheck 用 `CMD-SHELL`(已在 commit `0cf9ea2` 修复,但 redis 容器未重建)

## 服务器操作 5 个坑

1. **sudoers 限制** - `<REDACTED_SSH_USER>` 只能 sudo docker / nginx / xray / git,不能 sudo cp / nohup / bash 内部命令
   - 复制文件到 /opt: `sudo docker run --rm -v /opt:/opt alpine cp ...`
2. **SSH key + sudo git** - `sudo git` 重置 HOME 读不到 SSH config,git pull 失败
   - 解决: 先 `~/seekall` git pull,再 `docker run --rm -v` cp 到 `/opt/seekall-v0.5`
3. **/opt/seekall-v0.5 无 .git** - 是从 home cp 来的,git 历史在 `~/seekall`
4. **github.com-seekall Host** - 服务器 `~/.ssh/config` 配了 `github.com-seekall` 别名 + deploy key,clone 用 `git@github.com:donggua12339/seekall.git`(不是 github.com-seekall)
5. **redis MISCONF** - 如果 API health 又 degraded,先查 `df -h` 磁盘空间 + `/opt/seekall-v0.5/docker/redis/data/` 权限(redis UID 999)
