## 正文（300 字内）

做学术研究最痛苦的是在 arxiv、crossref、pubmed 之间来回切，同一个词搜 3 遍 😩

试了 SeekAll，一个搜索规则引擎 SDK。¥1 试用 7 天，分享一下体验：

📦 安装：npm i @seekall/sdk，3 行代码跑起来
🔧 规则：默认 0 规则（合规设计），自己写或装 npm 包
⚡ 性能：试用版 5 并发 + 8s 超时，比免费版快
💡 亮点：搜索词只在本机跑，服务端零接触（隐私好）
🎨 适合：开发者 / 研究人员，要会写代码（10 行就够）

对比免费版：
· free: 3 并发 / 10s 超时 / 无缓存
· trial ¥1: 5 并发 / 8s 超时 / 无缓存
· monthly ¥18: 10 并发 / 5s 超时 / 5min 缓存

¥1 试用适合先体验，觉得好用再升级。买 license 通过 WM 发卡网，卡密激活，不集成支付 SDK（合规）。

适合人群：会写代码 + 做学术研究 / 技术调研的开发者。
不适合：想要"一键搜索全网"零门槛的普通用户（SeekAll 是 SDK 不是网站）。

文档站 seekall.winmelon.cn
npm i @seekall/sdk
