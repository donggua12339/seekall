## 正文（300 字内）

做搜索聚合工具最大的问题不是技术，是合规 🤔

如果默认塞一堆规则，用户搜到违规内容，平台要担责。所以我做了 5 级风险评级：

🟢 L0 学术纯净（arxiv / crossref / pubmed）-> 公开免费
🔵 L1 通用开源（GitHub / HackerNews）-> 公开免费
🟡 L2 社区评审 -> 公开但需评审
🟠 L3 高风险 -> 仅 admin 可见
🔴 L4 极高风险 -> 永不公开

核心设计：
· 服务端不调任何资源站（代码里没有 axios/fetch）
· L3-L4 永不公开，即使付费也不行
· 不做评论 / 论坛（避免 UGC 责任）
· 规则市场只索引"工具"，不索引"资源"

工具是中性的，但数据源不是。SeekAll 做引擎，你来决定搜什么，各自合规各自担 🛡️
