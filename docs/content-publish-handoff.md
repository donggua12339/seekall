## 项目背景（30 秒了解）

SeekAll 是一个**中立的搜索规则引擎 SDK + 规则市场**（不是搜索网站）。

- 仓库：https://github.com/donggua12339/seekall（private）
- 文档站：https://seekall.winmelon.cn
- npm 包：`@seekall/sdk` + 17 个规则包
- 定位：工具中性合规，规则在用户本机跑，服务端零接触资源
- 作者 GitHub：donggua12339

### 配图制作

小红书需要 9:16 竖图。每个卡片文件底部有"配图建议"，按建议制作。

**工具推荐**（任选一个）：

- **Canva**（https://canva.com）：模板多，免费够用
- **Figma**：自由度高
- **截图 + 标注**：VS Code 代码截图 + 手机截图

**配图风格**：

- 深色/蓝色科技风（和 SeekAll 品牌色 #3aa675 绿搭配）
- 代码截图用 VS Code 深色主题（One Dark Pro 或 Dracula）
- 对比图用左右分栏（左：传统聚合网站 / 右：SeekAll）
- 表格图用颜色区分 L0-L4（绿/蓝/黄/橙/红）

**每个卡片的配图清单**：

**卡片 1**（npm 包也能跑搜索）：

1. 封面：终端运行截图 + 标题文字"npm 包也能跑搜索？"
2. 架构图：用户机器 → SDK → npm 规则
3. 代码截图：3 行代码（createEngine + search）
4. 对比图：聚合搜索网站 vs SeekAll

**卡片 2**（5 级风险评级）：

1. 封面：5 级评级表格 + 标题"5 级风险评级"
2. 评级详解：每级一个色块卡片
3. 架构对比：传统爬取 vs 本机执行
4. 红线清单：5 条不可逾越的红线

**卡片 3**（¥1 试用体验）：

1. 封面：终端截图 + "¥1 试用 7 天"
