# DMCA 流程

## DMCA 邮箱

`1660069758@qq.com`

接收所有版权侵权举报邮件。

## 处理流程

```
收到邮件 -> admin 审核 -> 关键词过滤验证 -> takedown 表记录
                                                        ↓
                                              URL 加入 blocklist
                                                        ↓
                                              触发 Provider 过滤
```

## 响应时间

24h 内人工响应。
工作日通常 4h 内首次回复。

## 邮件模板

举报邮件需包含：

1. 侵权 URL
2. 原作品信息（标题 + 版权所有者）
3. 举报人身份证明（版权所有者或授权代表）
4. 联系方式
5. 善意声明
6. 签名（电子签名即可）

## 误报申诉

若你认为 takedown 是误报：
- 发邮件到同一邮箱
- 标题前缀 `[COUNTER-NOTICE]`
- 提供 proof of authorization
- 7 个工作日内复审
