# 评审工作流

## L0 / L1（自动 + 抽查）

```
作者提交 -> 自动检查 npm 包是否存在 -> 入库 -> admin 抽查
                                          ↓
                                       异常下架
```

自动检查项：
- npm 包能 install
- 导出对象符合 Rule 接口
- riskLevel 字段存在
- 包大小 < 1MB（防投毒）

## L2（社群评审，M2 起步）

```
作者提交 -> 入暂存区 -> 社群评审（≥3 个老用户赞同）-> admin 终审 -> 入库
```

社群评审规则：
- 评审员需 ¥18 月卡及以上
- 评审员需无封禁记录
- 评审员不能评审自己提交的规则

## L3 / L4（仅 admin 创建）

L3/L4 规则**不接受社区提交**，仅 admin 可创建。
仅作审计用，不对非 admin 可见。

## 降级机制

- L2 规则被举报且查实 -> 下架
- L0/L1 规则被举报且查实 -> 下架 + 作者封禁
- 作者累计 3 次违规 -> 永久封禁

## 评审员奖励

每月活跃评审员（≥5 次有效评审）-> 1 个月月卡会员免费。
