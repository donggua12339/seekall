# 会员档位

SeekAll 不强制付费。免费可用 L0-L1 规则。

| 档位 | 价格 | 时长 | 权限 |
|---|---|---|---|
| 免费 | ¥0 | 永久 | L0-L1 规则 |
| 试用 | ¥1 | 7 天 | L0-L2 规则（每账号限购 1 次） |
| 月卡 | ¥18 | 30 天 | L0-L2 + 上传规则（5 条/月） |
| 永久 | ¥68 | 永久 | L0-L3 + 上传规则 + 作者徽章 |

## 主推永久

¥68 永久是主推档：
- 服务器钱一次回笼
- 用户无续费焦虑
- 简化财务（不用做订阅系统）

## 购买渠道

通过 WM 发卡网（你另一个项目）分发：
1. SeekAll admin 在卡密管理页生成 license code
2. WM 卡 webhook 半自动同步到商品页
3. 用户在 WM 卡付款 -> 拿到 code -> 在 SeekAll 兑换

## 邀请码机制

老用户（任一付费档）每月可发 3 个 ¥1 试用码：
- 给朋友体验
- 给小红书 / 群里发试用
- 防羊毛：每月限 3 个，下月重置

详见 [试用码机制](trial-code)。
