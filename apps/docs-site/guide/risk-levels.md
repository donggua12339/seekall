# 5 级风险评级 (L0-L4)

每条 Rule 在发布到市场时必须标注风险级别。

| 级别 | 含义 | 典型场景 | 可见性 |
|---|---|---|---|
| L0 | 学术纯净 | arxiv.org / crossref.org / pubmed | 所有人 |
| L1 | 官方 API | 厂商提供公开 API 的资源站 | 所有人 |
| L2 | 混搜警告 | 聚合型资源站（可能含版权内容） | 会员可见 |
| L3 | 高风险 | 论坛 / 网盘类（需审核） | admin 可见，仅作审计 |
| L4 | 严重侵权源 | 盗版论坛 / 破解站 | admin 可见，仅作审计 |

## 评级原则

- **默认严格**：拿不准时，按高一档标
- **就高不就低**：规则覆盖多种来源时，按风险最高的源标
- **不可降级**：L3/L4 规则永远不能降到 L0/L1（社区评审可降 L2->L1）

## 评审机制

L0/L1：作者自标，admin 抽查
L2：作者申请 + 社群评审（M2 起步）
L3/L4：仅 admin 可创建，仅作审计

详见 [评审工作流](/rules/review)。
