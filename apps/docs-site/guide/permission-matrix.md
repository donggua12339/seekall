# 5 维权限矩阵

每条 Rule 有 5 个权限维度，严格映射会员档：

| 权限 | 含义 | 默认 |
|---|---|---|
| View | 在市场列表里看到 | L0/L1 所有人可见 |
| Run | 在本机执行搜索 | 安装即可执行 |
| Save | 保存搜索结果到本地 | 免费用户允许 |
| Upload | 上传自定义规则到市场 | ¥18 月卡及以上 |
| Author | 申请作者徽章 | ¥68 永久 |

## 会员档映射

| 档位 | View | Run | Save | Upload | Author |
|---|---|---|---|---|---|
| 免费 | L0-L1 | L0-L1 | ✓ | ✗ | ✗ |
| ¥1 试用 (7天) | L0-L2 | L0-L2 | ✓ | ✗ | ✗ |
| ¥18 月卡 | L0-L2 | L0-L2 | ✓ | 5 条/月 | ✗ |
| ¥68 永久 | L0-L3 | L0-L3 | ✓ | 不限 | ✓ |

## 重要约束

- L3/L4 规则**永远**不对非 admin 可见（即使付费）
- Upload 权限受 5 条/月限制（¥18 月卡），避免市场被刷
- Author 徽章是荣誉性，不影响功能权限
