# 它是什么

SeekAll 是三件事的组合：

1. **一个 npm 包** - `@seekall/sdk`，给你一个搜索引擎框架
2. **一个规则市场** - 规则由社区贡献，5 级风险评级
3. **一个 BaaS** - 账号、规则订阅、付费授权

## 工作方式

```
你的代码
   ↓
@seekall/sdk
   ↓
跑所有已安装的 Rule（在你机器上）
   ↓
汇总 + 去重
   ↓
返回结果给你
```

服务端只负责：
- 账号 + 会员授权
- 规则市场的列表 + 评审工作流
- DMCA takedown 邮箱接收

服务端**不**做：
- 不替你跑规则
- 不存搜索结果
- 不向任何资源站发 outbound 请求

## 为什么这样设计

法律上：**工具中性**。SeekAll 是一个 npm 包，做什么由用户写的规则决定。
技术上：**用户机器算力**。规则执行分散在用户机器，服务端不需要扩容。
产品上：**生态而非应用**。规则市场让贡献者参与，而不是单一团队维护。
