# 它不是什么

明确边界，避免误用：

## ❌ 不是网盘搜索网站

SeekAll 不提供 web 界面让你输入关键词搜资源。
你想搜，你自己用 SDK 写代码。

## ❌ 不是盗版资源下载工具

SeekAll 默认不内置任何指向盗版资源的规则。
规则由社区贡献，5 级风险评级。L3/L4 规则仅 admin 可见，仅作审计。

## ❌ 不是中心化搜索引擎

SeekAll 服务端不替你跑规则。
所有规则在你的机器上执行，结果汇总去重。

## ❌ 不教用户接盗版源

文档里**不会**出现：
- "如何接夸克网盘"
- "如何搜 123pan"
- "如何下 magnet"

文档只教 SDK 怎么用、Rule 接口怎么实现。
